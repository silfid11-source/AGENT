# References

이 폴더는 ShowPark AI Studio 에이전트가 참고할 예시 자료를 넣는 곳입니다.

## 사용 방법

아래 폴더에 `.txt`, `.md`, `.csv` 파일을 넣어두면 레퍼런스 분석 자동화가 읽습니다.

- `brand_guides`: 브랜드 톤, 금지 표현, 고객 정보
- `captions`: 마음에 드는 인스타 캡션 예시
- `scripts`: 릴스 대본 예시
- `image_prompts`: 이미지 프롬프트 예시
- `video_prompts`: 영상 프롬프트 예시
- `urls.txt`: 참고하고 싶은 웹페이지 URL 목록

고객 자료나 실제 레퍼런스 원본은 GitHub에 올라가지 않도록 `.gitignore`에 제외되어 있습니다.
